# annetest

เว็บไซต์โปรไฟล์ส่วนตัวของ **มณทิรา** — ธีมกล้องฟิล์มโกดัก หน้าเดียวจบ ไม่มี build step ไม่มี dependency

🔗 **https://bu-digitalmarketing.github.io/annetest/**

## ดูเว็บบนเครื่อง

เปิด `index.html` ด้วยเบราว์เซอร์ได้เลย หรือถ้าอยากให้รูปในโฟลเดอร์ `img/` โหลดครบ ให้รันเซิร์ฟเวอร์เล็ก ๆ:

```
python3 -m http.server 4173
```

แล้วเปิด http://localhost:4173

## ธีม

ชุดสีอิงกล้องฟิล์มโกดัก — เหลือง `#ffb81c`, แดง `#e8251f`, อำพัน `#e07a1f`
มีเกรนฟิล์ม แสงรั่ว (light leak) ขอบมืด แถบฟิล์มรูหนามเตย และกรอบรูปอัดพร้อมวันที่สแตมป์
สลับโหมดมืด/สว่างได้ที่ปุ่มมุมขวาบน (จำค่าไว้ใน localStorage)

## รูปภาพ

รูปใน `img/` ทั้งหมดเป็น **ภาพกราฟิกสมมุติ** ที่สร้างขึ้นเป็น SVG ในโทนฟิล์มโกดัก ไม่ใช่ภาพถ่ายจริง
เปลี่ยนเป็นรูปจริงได้โดยวางไฟล์ลง `img/` แล้วแก้ path ใน `PROFILE`

| ไฟล์ | ใช้ที่ไหน |
|---|---|
| `img/cover.svg` | รูปปกหน้าแรก |
| `img/film-1.svg` … `film-6.svg` | แกลเลอรี |

## แก้ข้อมูล

ข้อมูลทั้งหมดอยู่ในตัวแปร `PROFILE` ท้ายไฟล์ `index.html` — ไม่ต้องแตะ HTML/CSS

| ฟิลด์ | ใช้ทำอะไร |
|---|---|
| `name` / `brand` | ชื่อบนหน้าเว็บ และชื่อย่อมุมซ้ายบน |
| `filmStock` / `frame` | ข้อความบนขอบกรอบรูป เช่น `Kodak Gold 200 · 35mm` และ `Frame 12A` |
| `photo` | รูปปก เช่น `"img/cover.svg"` หรือรูปจริงของคุณ |
| `ticker` | ข้อความในแถบฟิล์มที่วิ่ง |
| `about` | ย่อหน้าแนะนำตัว |
| `interests` | การ์ด bento — `glow` คือสีแถบข้างการ์ด |
| `journey` | ไทม์ไลน์ |
| `gallery.images` | รูปแกลเลอรี แต่ละใบใส่ `{ src, cap, frame }` |
| `links` | ช่องทางติดต่อ |

ข้อความที่อยู่ในวงเล็บ `[...]` คือช่องที่ยังรอเติมข้อมูลจริง

## อัปเดตเว็บ

แก้ไฟล์แล้ว push — GitHub Pages จะ deploy ให้เองภายในไม่กี่สิบวินาที

```
git add -A && git commit -m "อัปเดต" && git push
```
