# annetest

เว็บไซต์โปรไฟล์ส่วนตัวของ **Anne Montira** — หน้าเดียวจบ ไม่มี build step ไม่มี dependency

## ดูเว็บ

เปิด `index.html` ด้วยเบราว์เซอร์ได้เลย

## แก้ข้อมูล

ข้อมูลทั้งหมดอยู่ในตัวแปร `PROFILE` ท้ายไฟล์ `index.html` — ไม่ต้องแตะ HTML/CSS

| ฟิลด์ | ใช้ทำอะไร |
|---|---|
| `name` / `brand` | ชื่อบนหน้าเว็บ และชื่อย่อมุมซ้ายบน |
| `photo` | รูปโปรไฟล์ — วางไฟล์ไว้โฟลเดอร์เดียวกัน แล้วใส่ชื่อไฟล์ เช่น `"photo.jpg"` |
| `stickers` | ข้อความสติกเกอร์ 2 อันข้างรูป |
| `ticker` | ข้อความในแถบวิ่ง |
| `about` | ย่อหน้าแนะนำตัว |
| `interests` | การ์ด bento — `glow` คือสีแสงของการ์ดแต่ละใบ |
| `journey` | ไทม์ไลน์ |
| `gallery.images` | รูปในแกลเลอรี เช่น `["p1.jpg","p2.jpg"]` |
| `links` | ช่องทางติดต่อ |

ข้อความที่อยู่ในวงเล็บ `[...]` คือช่องที่ยังรอเติมข้อมูลจริง

## ฟีเจอร์

- พื้นหลัง gradient mesh ขยับได้ + grain texture
- โหมดมืด/สว่าง (จำค่าไว้ใน localStorage)
- Bento grid พร้อมแสงเรืองตามเมาส์
- แถบข้อความวิ่ง หยุดเมื่อเอาเมาส์ชี้
- รองรับมือถือ และ `prefers-reduced-motion`
